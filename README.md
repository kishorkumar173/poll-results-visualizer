# 📊 Poll Results Visualizer Dashboard

## 🚀 Overview

This project is an interactive dashboard that analyzes poll/survey data and converts it into meaningful insights using visualizations.

Users can upload their own dataset and instantly explore trends, preferences, and satisfaction levels.

---

## 🎯 Problem Statement

Raw survey data is difficult to interpret and time-consuming to analyze manually.
This project solves that by transforming raw data into interactive charts and insights.

---

## 💡 Solution

* Upload CSV dataset
* Apply filters (Region, Product)
* Generate real-time visualizations
* Extract key insights automatically

---

## ✨ Features

* 📂 Upload your own dataset
* 🎛 Interactive filters
* 📊 Bar, Pie, and Region charts
* 📈 Key metrics (Total, Avg Rating, Top Product)
* 🧠 Insight generation

---

## 🛠 Tech Stack

* Python
* Pandas
* Plotly
* Streamlit

---

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```
